One single-line safety warning label that should come printed on every human being (108 characters):

> WARNING: Human may suddenly explain something you already know, at length, with confidence, and incorrectly.

The joke is recognition: the label reads like a real printed warning, and the turn lands on the very last word.

## Run it

```sh
python3 main.py
```

Writes the label to `/output/entry.txt` (standard library only, deterministic — the same line on every run).
